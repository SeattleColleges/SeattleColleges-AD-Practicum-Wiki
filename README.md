## Beginner Contributor Workflow

If you are new to the Practicum GitHub workflow, follow these steps when contributing:

1. Create or claim an issue
2. Create a branch for your assigned work
3. Make your documentation or code changes
4. Commit and push your changes to GitHub
5. Open a pull request for review
6. Respond to feedback from reviewers if needed

Creating issues before starting work helps the team track sprint progress and project contributions correctly.

## Contribution Tips

- Keep pull requests small and focused
- Write clear commit messages
- Test your changes before opening a pull request
- Ask questions if you are unsure about workflow steps
